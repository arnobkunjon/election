# Bangladesh dataset (data/bd)

Test/prototype data only. This folder follows the Electoral Region Format v0.1
(see `spec/electoral-region-format.md`).

## Files

- `country.json` — country metadata, levels, election types. Hand-written.
- `regions.json` — generated by `node tools/build-bd-from-sources.mjs`. Do not edit by hand.
- `constituency-mapping.template.json` — empty template with two clearly FAKE example
  entries showing how constituencies composed of upazilas will look. Not real data.

## Sources and licenses

### Administrative divisions (divisions, districts, upazilas, unions)

- Source: [nuhil/bangladesh-geocode](https://github.com/nuhil/bangladesh-geocode)
  (files used: `divisions/divisions.json`, `districts/districts.json`,
  `upazilas/upazilas.json`, `unions/unions.json` from the `master` branch).
- License: **MIT** — checked in the source repo (`LICENSE` file: "The MIT License (MIT),
  Copyright (c) 2014 Nuhil Mehdy"). MIT permits reuse in an MIT-licensed project; the
  attribution is noted in the root `LICENSE`.
- The source itself says its data was taken from bangladesh.gov.bd, wikipedia.org and
  maps.google.com. We keep the source's own numeric ids as `codes.source` so every
  region can be traced back.

### Boundaries / geometry (planned, NOT used yet)

- Planned source: OCHA COD-AB Bangladesh —
  https://data.humdata.org/dataset/cod-ab-bgd
- **Its license must be checked before use.** No geometry files are included in this
  prototype; `regions.json` has no `geometry` fields yet.

## Known gaps / TODO

- [ ] **TODO: constituency mapping.** The real 300 Jatiya Sangsad seat → upazila mapping
      must be filled into `constituency-mapping.template.json` (and later merged into
      `regions.json`) from the Election Commission or Wikipedia
      (https://en.wikipedia.org/wiki/List_of_constituencies_of_the_Jatiya_Sangsad).
      It must be **verified by a human** before use. The two entries currently in the
      template are fake examples only.
- [ ] Wards (rank 4) are declared as a level but have no regions yet; the source repo
      does not cover wards. Needed for union parishad ward-member elections.
- [ ] City corporations are declared as a level but have no regions yet.
- [ ] Election types in `country.json` (seat counts such as 9 ward members and 3
      reserved women members) are **illustrative** and must be verified against current
      law before production use.
- [ ] Spelling inconsistencies inherited from the source (e.g. district id 1 is
      "Cumilla" in the CSV but "Comilla" in the JSON export; some older division names).
- [ ] Reserved women seats at parliament level (up to 50 nominated seats) are not
      modelled yet.
- [ ] Geometry (boundaries) missing entirely — see COD-AB above.

## Rebuilding

```bash
node tools/build-bd-from-sources.mjs   # regenerate regions.json
node tools/validate.mjs data/bd        # validate the folder
```

If a source file cannot be fetched or its columns change, the build script stops and
says so — it never invents data.
